# iOS / iPadOS 客户端配置教程（Shadowrocket / Stash）

> 前置条件：已注册 [yydsflight.com](https://yydsflight.com) 并购买套餐，手上已有**订阅地址**。
> 注意：iOS 客户端需使用**非中国大陆区 Apple ID** 在 App Store 下载。

## 方案一：Shadowrocket（小火箭，¥3 付费）

### 1. 下载
用海外 Apple ID 在 App Store 搜索 **Shadowrocket**（小火箭），¥3 购买安装。

### 2. 导入订阅（3 选 1）
- **扫码**：控制台打开订阅二维码，Shadowrocket 左上角 `+` → 扫一扫
- **粘贴**：`+` → 类型选 Subscribe → URL 粘贴订阅地址 → 保存
- **一键导入**：登录官网控制台，在手机浏览器点「一键导入」自动唤起

### 3. 连接
1. 点刚添加的订阅，进入节点列表
2. 顶部选一个节点，点右上角「⚡」测速，选延迟最低的
3. 首页顶部的「全局路由」开关打开
4. 首次连接弹「允许添加 VPN 配置」→ 允许 → 输入锁屏密码
5. 状态栏出现 `VPN` 图标 = 成功

---

## 方案二：Stash（¥3，Clash 内核）

1. App Store 搜索 **Stash**，购买安装
2. 首页「从 URL 导入」→ 粘贴订阅地址
3. 选节点 → 打开开关 → 允许 VPN 配置

---

## 常见问题

- **App Store 搜不到小火箭？** 国区下架了，需换海外 Apple ID。
- **连上但上不了网？** 换个节点试试；确认订阅未过期、流量未耗尽。
- **电池图标旁 VPN 消失？** 到 设置 → 通用 → VPN 与设备管理 里手动连。
