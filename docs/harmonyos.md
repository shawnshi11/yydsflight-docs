# 鸿蒙 HarmonyOS 客户端配置教程

> 前置条件：已注册 [yydsflight.com](https://yydsflight.com) 并购买套餐，手上已有**订阅地址**。

鸿蒙分两种情况，请先确认你的系统版本：

- **HarmonyOS 4.x 及以下**（兼容 Android APK）→ 按下方「方案一」
- **HarmonyOS NEXT（纯血鸿蒙，5.0+）** → 按下方「方案二」

---

## 方案一：HarmonyOS 4.x（装 Android 客户端）

4.x 及以下可直接安装 Android 客户端，与普通安卓一致：

1. 下载 **v2rayNG** 或 **Clash Meta (CMFA)** APK（见 [Android 教程](android.md)）
2. 设置里允许「安装未知应用」并安装
3. 导入订阅地址（扫码 / 粘贴 / 一键导入）
4. 选低延迟节点 → 开启连接

---

## 方案二：HarmonyOS NEXT（纯血鸿蒙）

纯血鸿蒙不再兼容 APK，需使用鸿蒙原生客户端：

1. 打开 **华为应用市场**，搜索鸿蒙版客户端（如 sing-box 鸿蒙版 / 同类机场客户端）
2. 或从官网控制台获取**手动配置参数**（服务器地址 / 端口 / 密码 / 加密方式等）
3. 在客户端里按参数逐个填入，保存后连接

> 各鸿蒙客户端的入口位置略有差异，核心就是「**导入订阅地址**」或「**填服务器参数**」两步。实在找不到入口，联系客服 QQ 2732683587 获取对应客户端的逐步指引。

---

## 常见问题

- **鸿蒙 NEXT 没有可用的机场客户端？** 鸿蒙生态还在成长期，客户端选择较少；联系客服获取当前推荐方案。
- **装 APK 提示不兼容？** 说明你已是 NEXT 版本，走方案二。
