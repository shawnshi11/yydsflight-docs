# Android 客户端配置教程（v2rayNG / Clash Meta）

> 前置条件：已注册 [yydsflight.com](https://yydsflight.com) 并购买套餐，手上已有**订阅地址**。

## 方案一：v2rayNG（免费开源）

### 1. 下载
- 官网直出 APK：[yydsflight.com/download](https://yydsflight.com) 教程页有入口
- 或官方源：[v2rayNG Release](https://github.com/2dust/v2rayNG/releases)（选 `v2rayNG_x.x.x_arm64-v8a.apk`）

### 2. 导入订阅（3 选 1）
- **扫码**：控制台打开订阅二维码 → v2rayNG 右上角 `+` → 扫一扫
- **粘贴**：`+` → 从剪贴板导入（先复制订阅地址）
- **手动**：`+` → 手动输入服务器（不推荐，用订阅更省事）

### 3. 连接
1. 左上角菜单 → 「订阅设置」→ 更新订阅
2. 回到主界面，点一个节点选中
3. 点右下角灰色圆钮，变绿 = 连接成功
4. 状态栏出现钥匙/VPN 图标

---

## 方案二：Clash Meta（CMFA，官网直出）

1. 从官网教程页下载 CMFA APK 安装
2. 首页「配置」→ `+` → 从 URL 导入 → 粘贴订阅地址 → 保存并启用
3. 首页「代理」选一个低延迟节点
4. 打开「系统代理」开关

---

## 常见问题

- **安装 APK 提示"未知来源"？** 设置里允许「安装未知应用」即可。
- **连上后个别 App 无网？** 换节点；部分 App 检测代理，属正常。
- **更新订阅失败？** 检查网络能开 yydsflight.com，再更新一次。
