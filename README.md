## 🚀 三步快速开始

1. **注册账号** —— 打开 [yydsflight.com](https://yydsflight.com)，邮箱验证码注册
2. **选择套餐** —— 从 1 元体验到按月套餐，支付宝扫码，即时到账
3. **导入订阅** —— 复制专属**订阅地址**（或扫码 / 一键导入），粘贴进客户端 → 更新订阅 → 选低延迟节点 → 连接

> 拿到订阅地址后，选任意一个客户端即可，**订阅地址是通用的**，换客户端不用重新购买。

## ❓ 常见问题

<details>
<summary><b>什么是「订阅地址」？</b></summary>

订阅地址（Subscription URL）是你专属的一串链接，形如 `https://yydsflight.com/cctv/...`。把它粘贴进客户端，客户端会自动拉取一批**节点**（服务器列表），你只需选一个延迟低的连上即可。**这个地址绑定了你的账号，请勿外泄/分享**。

</details>

<details>
<summary><b>机场、VPN、翻墙、科学上网是一回事吗？</b></summary>

本质上都是「通过代理节点中转流量，访问境外网络」。「机场」是圈内对**付费节点订阅服务**的俗称；VPN 是其中一种技术形态。YYDS Flight 提供的就是机场服务：付费订阅 → 订阅地址 → 客户端一键拉取节点 → 按需连接。

</details>

<details>
<summary><b>连不上 / 很慢怎么办？</b></summary>

① 客户端里「更新订阅」；② 换一个延迟更低的节点；③ 仍不行请在官网控制台提交工单或联系客服。

</details>

<details>
<summary><b>支持几台设备同时在线？</b></summary>

以你购买的套餐为准。订阅地址绑定账号，设备超限会被限制，请勿分享。

</details>
